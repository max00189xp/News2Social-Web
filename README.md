# 男性泌尿科新聞與社群衛教資料庫

以繁體中文呈現收錄的新聞／研究來源與 FB、IG、Threads 生成草稿。所有生成文案保留待審狀態，禁止發布的流程測試稿另外隔離顯示。

- 左欄：依台北時間的收錄／生成年月分類。
- 上欄：日期篩選、主題搜尋與日期＋新聞主題分頁。
- 內容：原始來源標題、來源日期、摘要或取得範圍、來源連結、三平台草稿及版本。
- 字體：所有文字至少 20px；小螢幕自動調整排列。
- 單一 `index.html` 包含樣式與資料，可直接下載開啟；不使用第三方字型、追蹤器或外部程式。

本儲存庫只保存公開分享用的 HTML 與說明；不包含私人狀態資料庫、API 金鑰、HackMD 私人連結、樣本或稽核日誌。資料由私人搜尋專案的匯出工具以明確欄位清單產生，搜尋後自動更新；無內容變動時不建立空提交。

AI 生成內容尚待醫療專業人員審核；本資料庫供審稿與討論，不代表已核准的醫療建議，不會自動發布至 FB、IG 或 Threads。
